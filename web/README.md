# Dashboard (`web/`)

React 19 + TypeScript + Vite + Tailwind 4 + Recharts. All numbers come from `public/data/results.json`, generated by `../scripts/build_web_data.py` from `../results/`.

```bash
npm ci
npm run dev       # local development
npm run build     # type-check and build into dist/
```

See `../docs/WEBSITE_GUIDE.md` for pages, data flow and deployment.
